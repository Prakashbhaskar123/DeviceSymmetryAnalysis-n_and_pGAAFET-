# DeviceSymmetryAnalysis-n_and_pGAAFET-
In this repo IV and CV curves symmetry is analysed using python. It includes both n and p type gaafets




Device Symmetry Analysis

Python tools to parse Sentaurus TCAD electrical-characteristic output files (.plt, DF-ISE text format) and plot Id-Vd / Id-Vg curves for n-type and p-type GAAFETs, in order to check source/drain symmetry.

What's in this repo
plot_gaa_symmetry.py — parses .plt files and generates comparison plots
*.plt — Sentaurus device simulation output files (DF-ISE text format)
demo_plots.png — example output plot
